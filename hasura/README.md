# Hasura GraphQL Engine - Metadata
#
# This directory contains the Hasura metadata configuration, which defines:
# - Which analytics tables are tracked and exposed via GraphQL
# - Relationships between tables (for nested queries)
# - Role-based permissions (user/anonymous)
#
# The metadata can be applied to a running Hasura instance using:
#   hasura metadata apply --endpoint https://graphql.trigpointing.me --admin-secret <secret>
#
# Or exported from a running instance:
#   hasura metadata export --endpoint https://graphql.trigpointing.me --admin-secret <secret>
#
# Note: The admin secret is generated by Terraform (random_password.hasura_admin_secret)
# and can be retrieved from the ECS task definition environment variables.
